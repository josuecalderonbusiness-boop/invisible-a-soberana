## NUEVOS TIPOS DE EJERCICIO

### `field:'match-slide'`
Ejercicio de emparejamiento con slide automático. Propiedades:
```javascript
{
  id: 'ejercicio_id',
  type: 'tool',
  tema: N,
  field: 'match-slide',
  doneTitle: 'Texto pantalla final',
  doneSub: 'Subtexto pantalla final',
  matchItems: [
    {
      text: 'Situación en segunda persona',
      correct: 'G', // o 'H' (Gobernada / Habitada)
      error: 'Explicación conceptual cuando falla'
    }
  ]
}
```
**Comportamiento:**
- Una pregunta a la vez con slide automático (300ms delay)
- Botón correcto → verde → avanza automáticamente
- Botón incorrecto → popup oscuro vino/dorado con explicación conceptual
- Botón "Continuar" oculto hasta completar todas las preguntas
- Estado guardado en `window._matchState[exId]`

### Funciones JS asociadas
```javascript
matchAnswer(exId, idx, btn, val)  // evalúa respuesta, avanza o muestra popup
matchClosePopup(exId)             // cierra popup de error
```

## CUADERNO ANIMADO (Pausa Workbook)

### Detección
- Se activa cuando `ex.label.includes('Pausa Workbook')`
- Field debe ser `star-textarea` (no `declaration`)

### Funciones JS
```javascript
wbAbrir(exId)       // flip portada → zoom → fullpage + fondo vino
wbCerrar(exId)      // cierra hoja → vuelve cuaderno + fondo beige
wbGuardar(exId)     // si tiene followUp → flip a segunda hoja; si no → wbGuardarFinal
wbGuardarFinal(exId) // muestra botón "Ver resumen", cierra cuaderno
```

### Soporte de declaración + followUp
Si el ejercicio tiene `declaration`, el cuaderno muestra:
1. Texto de la declaración en cursiva (fondo vino suave, borde dorado izquierdo)
2. Campo `fieldLabel` como label del textarea
3. Al guardar: flip a segunda hoja con `followUp.question`

### Tag del cuaderno
```javascript
// Solo muestra "🪞 Espejo X de 3" si el label lo dice explícitamente
${ex.label && ex.label.includes('Espejo') ? '🪞 ' + ex.label : ''}
```

## PRINCIPIOS TÉCNICOS (PowerShell)

- **Ediciones simples:** `fix.ps1` con `Get-Content -Encoding UTF8 -Raw` + `Set-Content -Encoding UTF8`
- **HTML con caracteres especiales:** guardar en archivo separado e inyectar con `Substring + IndexOf`
- **Emojis en `-replace`:** NO usar — corrompen el archivo. Usar Ctrl+H en VSCode
- **Comillas dobles en strings:** guardar fragmento en archivo separado
- **Recovery:** `git restore public/workbook/index.html` o `git revert <hash>`
- **Edición directa de líneas:** `$lines[N] = "..."` solo cuando `-replace` falla por comillas simples
